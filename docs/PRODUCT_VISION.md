# Product vision (summary)

Full specification: `docs/MASTER_PLAN.md` (ETHNOFLOW_CLAUDE_CODE_MASTER_PLAN.md v1.0).

**EthnoFlow Studio** turns a spontaneously played ethno melody (kaval, flute, gaida,
voice…) into finished music without losing the human performance and without requiring
prior music education. One desktop app, Windows first, combining:

1. **Music Academy** — Bulgarian-language interactive lessons from "what is sound" to a
   first composition.
2. **Live Instrument Lab** — microphone in, tuner, note/pitch contour, rhythm, waveform,
   sample recorder.
3. **Music Studio** — a real multitrack audio/MIDI editor with core DAW functions.
4. **Intelligent Accompanist** — rule-based (later AI-assisted) drone, chords, bass and
   Liquid DnB grooves that respect modality, drones, asymmetric metres and free tempo.
5. **Composition Coach** — explains *why* a suggestion works; technical fit, not taste.
6. **DAW Export** — WAV stems, MIDI, tempo map, markers, import README.

Principles that shape every phase: real audio first; beginner first, expert capable;
non-destructive; local-first/offline core; AI optional; explainable; reproducible
(seeds); accessible; open formats; no misleading scoring.

What Phase 0 delivers against this: the thinnest real slice of (2) — device selection,
recording with metering, waveform, playback, WAV import/export — proving the stack can
carry the rest.
