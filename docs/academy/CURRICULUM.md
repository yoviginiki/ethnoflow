# Академия — учебна програма (план, 2026-10-18)

Отговор на въпроса на собственика: „имаш ли план какво трябва да съдържа обучението —
максимално пълно и лесно: ноти, ритъм, всичко, теория, практика, тестове, упражнения“.
Този файл е планът. Той разширява MASTER_PLAN §4 (нива 0–6) и FEATURE_SPEC F6.1–F6.3 до
конкретни уроци, упражнения и проверки. Данните на уроците живеят в
`packages/lesson-content/lessons/*.json`, логиката (валидатор, генератори със seed,
оценка) в `crates/lessons`, екранът е „Научи музика“ (Начало › Академия).

## 1. Принципи

1. **Всичко офлайн, на български** (EN като втори език на заглавията и текста).
2. **Един урок = 5–10 минути.** Обяснение до 3 изречения → слушай (демонстрация, която
   приложението изсвирва само) → свири/пляскай/отговори → автоматична проверка с ясна
   обратна връзка → повтори, ако искаш → мини задача.
3. **Собственият инструмент.** Демонстрациите се свирят в обхвата на профила на инструмента
   (кавал в Ре, шакухачи 1.8/Ре, глас…); ако профилът има записани семпли, се ползват те,
   иначе вграденият синт „флейта“. Тунерът и микрофонът проверяват как свириш.
4. **Никакво наказание.** Няма streak, няма известия, няма „изгубен ден“. Напредъкът е
   локален файл; „премина“ значи изпълнен праг, не оценка на човека.
5. **Толеранс по ниво**: начинаещ ±30 c / ±120 ms, среден ±20 c / ±80 ms, напреднал
   ±10 c / ±50 ms (същите като тренажора). Всяко упражнение има генератор със seed —
   „Още веднъж“ дава нов, но възпроизводим вариант.
6. **Теорията е винаги с пример от приложението**: урокът за бурдон пуска реално ручило,
   урокът за размер пуска метронома с акценти, урокът за пространство върти Space.
7. **Речникът** е един (Помощ › Речник) и уроците сочат към него.
8. **Без фалшива сигурност** (CLAUDE.md правило 5/6): нищо не се „симулира“. Ако една
   проверка не може да се направи реално (напр. липсва микрофон), урокът го казва и
   предлага клавиатурата или само слушане.

## 2. Формат на урок (данни)

```json
{
  "id": "l1-04-pulse",
  "level": 1,
  "order": 4,
  "title": { "bg": "Пулс и темпо", "en": "Pulse and tempo" },
  "objectives": { "bg": ["..."], "en": ["..."] },
  "explanation": { "bg": "≤ 3 изречения", "en": "..." },
  "glossary": ["BPM", "такт"],
  "demo": { "kind": "clicks", "bpm": 90, "meter": [4, 4], "bars": 2 },
  "exercise": { "type": "rhythm_clap", "params": { "bpm": 90, "meter": [4, 4], "bars": 2 } },
  "pass": { "score": 0.7 },
  "quiz": [{ "q": {"bg": "...", "en": "..."}, "choices": [...], "answer": 1, "why": {...} }],
  "mini_project": { "bg": "...", "en": "..." },
  "next": "l1-05-meters"
}
```

Валидаторът (Rust, с тестове) отказва: непознат тип упражнение, липсващ превод, `next`
към несъществуващ урок, параметри извън обхват (напр. ±cents < 5), дублирани id-та.

## 3. Типове упражнения (каталог) и какво мерят

| Тип | Какво прави приложението | Какво прави ученикът | Как се проверява | Статус v1 |
|---|---|---|---|---|
| `quiz` | показва въпрос и 2–4 отговора | избира | правилен/грешен, с обяснение защо | v1 |
| `hold_tone` | казва нота (от профила/лада) | държи тона N секунди | тунер: секунди в ±tol; стабилност (σ cents) | v1 |
| `sight_reading` | показва име на нота (и апликатура, когато има) | свири я възможно най-бързо | тунер: улучена ли е, време за реакция | v1 |
| `hear_and_repeat` | свири нота/фраза (семпли от профила или синт) | повтаря я | `evaluate` от тренажора: ноти, cents, ms | v1 |
| `ear_interval` | свири два тона | избира интервала | правилен/грешен; показва двата тона | v1 |
| `ear_chord` | свири тризвучие | мажор/минор/sus/умалено | правилен/грешен | v1 |
| `ear_mode` | свири гама/лад | избира лада | правилен/грешен; показва стъпките | v1 |
| `ear_meter` | свири кликове с акценти | избира размера (2/4, 3/4, 4/4, 6/8, 7/8…) | правилен/грешен | v1 |
| `rhythm_clap` | метроном + показан ритъм | пляска/свири в микрофона | onset-и от микрофона срещу решетката: ms отклонение | v1 (от нивото на входа) |
| `play_along` | падащи ноти (тренажор Wait/Rhythm) | свири по нотите | докладът на тренажора | v1 (препраща към Свири) |
| `guided` | стъпки с реални проверки на състоянието на приложението | прави стъпките в екраните | напр. „има нов запис“, „ритъмът върви“, „Space ≥ 60 %“ | v1 (Урок №1) |
| `compose_task` | задание + шаблон на проект | създава фрагмент | guided + слушане, без автоматична оценка на „хубаво“ | v2 (Ниво 5) |
| `mix_task` | задание за микс (Coach) | върти контроли | измерими цели (пик, баланс на шините) | v2 (Ниво 6) |

## 5. Урок №1 „Древният кавал среща 174 BPM“ (guided, Phase 6 exit)

Сценарият от INSTRUMENT_MACHINE_CONCEPT §7, като стъпки с реални проверки:
1. Калибриране: изсвири дълъг тон (проверка: тунерът показва стабилен тон 2 s или
   профилът има ≥ 1 нота).
2. Ритъм: избери Liquid пресет, 174 BPM (проверка: ритъмът върви, bpm = 174).
3. Запис: изсвири 4–5 ноти (проверка: в проекта има нов запис с анализ ≥ 3 ноти).
4. Лад: избери от хипотезите (проверка: проектът има лад).
5. Атмосфера: Space до 70 % (проверка: master.space ≥ 0.6).
6. Запази пресет с бележка (проверка: нов пресет след началото на урока).

## 6. Напредък и тестове

- `<config>/academy/progress.json`: за всеки урок `{attempts, best_score, passed_at}`;
  за всяко ниво `{test_passed_at}`. Никакви streak-ове и известия.
- „Премина“ = score ≥ праг на урока (по подразбиране 0.7) при текущия толеранс.
- Тест на нивото: случайна извадка (seed) от квизовете и слуховите упражнения на нивото +
  една практика; праг 0.75. Може да се пропусне (урокът по-нататък не е заключен —
  препоръката е ред, не ключалка).
- Пътека за начинаещ на кавал/шакухачи (Ники): 0.1 → 0.4 → 1.1 → 1.4 → 1.5 → 2.1 → 2.3 →
  2.5 → 3.1 → 3.2 → Урок №1.

## 7. „Създай песен“ (Phase 5 водач) и Академията

Водачът е **същият guided двигател** (стъпки + проверки на състоянието), пуснат върху
екраните Старт от мелодия → Лад/Темпо → Карта → Фон → Експорт. Урок 5.6 го извиква.
Затова се строи веднъж: първо guided стъпките за Урок №1 (v1), после водачът (v2).

## 9. Кавал — база знания на собственика (2026-10-18 вечер)

`docs/kaval-baza-znania.md` (пръстовки за Ре кавал; обобщение на самоучителя на Bob Snider;
структурирани бележки по Любен Досев, „Методическо ръководство за овладяване на
орнаментиката в Южнотракийския кавалджийски стил“, 1994) влиза в Академията на три места:

| Част от базата | Къде е в приложението | Статус |
|---|---|---|
| Част 1, таблици с пръстовки | `packages/lesson-content/fingerings/kaval-d.json` → таб „Пръстовки“, схема до тунера (профил кавал), схема в „Прочети нотата“, „Дръж тона“ и „Чуй и повтори“ | FUNCTIONAL (vitest проверява пълнотата по регистри; визуална сверка от Ники предстои) |
| Част 2, самоучител | Кавал 1–7 (звук, пръсти/захват, първи регистър, регистри, ситнене, клепане, каба) | FUNCTIONAL |
| Част 3, Досев | Кавал 8–14 (вибрато, сечене, заместване, глисандо, акценти/АТ, къс трилер, приложение) — обяснение + квиз + четене на точния раздел; където е възможно, демонстрация/фраза (Пример 62 приблизително) | FUNCTIONAL като четене/квиз; измерване на самия орнамент = NOT STARTED |
| Целият документ | таб „База знания“: съдържание по части/глави (сканове със страници), търсене, таблици и цитати | FUNCTIONAL |

Следващи стъпки за кавалната пътека: измерване на вибрато (периодичност и посока на
отклонението по контура), откриване на сечене/АТ като кратки високи отклонения, нотните
примери от Досев като MIDI фрази за „Свири по ноти“ (само надеждно разчетените), таблицата
на Ники за алтернативни пръстовки на неговия кавал (редактор, F2.6 стъпка 2).
