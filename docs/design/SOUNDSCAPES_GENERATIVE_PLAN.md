# Soundscapes 2: генеративни композиции (план, 1.11.2026)

Собственикът (1.11.2026): „искам Soundscapes да е нещо, което се програмира да работи като
Atmospheric, но да прави цели композиции“ + пратена идея „Generative Ecosystem Engine“
(слоеве Drone / Pulse / Events / Texture, random walk, еволюция с акцентен инструмент,
следване на хармонията, светове-пресети, реактивен диригент от микрофона, 3D движение,
гранулиране, микро-наратив Intro → Development → Climax → Outro, време/метео).

Старият екран Soundscapes е слят в Атмосфера като изглед „Модули“ (същата стойка); името
Soundscapes се освобождава за този модул. Правилото остава: **асистентът предлага,
собственикът решава**; всеки етап е вертикален (двигател → състояние → UI → запазване →
мост → smoke → ръководство) и нищо не се симулира.

| Идея от текста | Вече съществува | Къде |
|---|---|---|
| The Drone / Texture | дрон, пад, стойка Атмосфера с 10 вида слоеве (noise, wind, texture, bells, pluck, loop, resonator, choir, bloom, cloud) | `crates/audio-engine` ambient, `Ambient.tsx` |

| Грануларен синтез на собствен файл | модул **Cloud** (зърно, плътност, позиция, сканиране, височина) | `LayerSource::cloud`, „+ Облак“ от Моите семпли |
| Макроси + „дишане“ | макроси intensity / brightness / motion / space / space_size / tonal_gravity / width / shimmer; автоматизация по ленти; сцени | `Macros`, `AutomationLane`, сцени в Атмосфера |
| Следване на хармонията | слоевете „в лада“ следват тоналния център на проекта; Живият акомпаниатор мести дрон/пад по фрази | `tonal: true`, `LiveFollowPanel`, intent |
| Наратив по секции | Карта на песента с енергия/плътност и „Следвай картата“ (секциите управляват шините) | `SongMapScreen`, `layers.ts` |
| Реактивен диригент (RMS, активност) | мониторът дава ниво и височина 50 ms; анализът има RMS/energy; Директорът (P3) има cue engine | `monitor.rs`, `crates/analysis`, `docs/ETHNOFLOW_LIVE_PERFORMANCE_DIRECTOR_SPEC.md` |

Липсват: **времева арка без карта на песента**, **случайни събития** (едноударни звуци с
вероятност, скорост и панорама), **пулс** (неперкусионен, идва и си отива), **плавен шум**
(Perlin/1-f) върху макросите, **орбитална панорама и разстояние**, **реакция на
микрофона** върху плътността, **соло линия при тишина**, **светове** като алгоритмични
профили, **време на деня / метео**.

## 2. Модел: „Пътуване“ (Journey) върху стойката

Soundscapes 2 не е нов синтезатор, а **диригент** над вече съществуващите двигатели
(дрон, пад, атмосфера, ритъм). Един документ `Journey` в проекта:

```
Journey {
  world: WorldId,                 // профил: кои слоеве, какви граници, какъв характер
  phases: [ { role: Intro|Development|Climax|Outro|Custom, seconds, targets: Macros + bus levels, allowed_kinds, event_density } ],
  loop: bool,                     // след Outro: пак Intro (с ново семе) или спира
  breathing: { depth, period_s, seed },      // 1/f дрейф върху cutoff / space / density
  events: { kinds, per_minute, velocity_spread, tension_p: 0.1, orbit: {speed_range, distance} },
  pulse: { on, period_s: 120..180, duty, source: "ostinato-lp" | "heartbeat" },
  reactive: { on, density_gain, silence_solo: bool, silence_s: 8 },
  seed: u64
}
```

Арката се изпълнява от таймер в UI слоя (както „Следвай картата“), а новите звукови
елементи (събития, пулс, орбита) са нови източници в двигателя. Запазва се в
`session.json`/проекта, пресетите са „светове“ в Библиотеката с бележки.

## 3. Етапи (всеки = вертикален срез със smoke стъпка и абзац в ръководството)

| Етап | Какво | Двигател | UI | Проверка |
|---|---|---|---|---|
| **S1 Арка** (1 ден) — **направен 1.11** като „светове → пътуване“ (`scapes.ts`, `ScapesScreen.tsx`, таб „Soundscapes“ във Фон; S4 дишането влезе тук чрез „walk“ лентите, S7 световете са шест рецепти без свои параметри още) | фази с продължителност и цели (макроси, нива на шините, кои видове слоеве са позволени); линия на времето с текущата фаза; ▶ Пътуване / ■; `loop` | — (пише в съществуващите макроси/нива с плавни рампи) | нов таб „Soundscapes“ във Фон: редактор на фази + линия | smoke: пусни арка 4 × 2 s, провери че макросите/нивата стигат целите |
| **S2 Събития** (1–2 дни) — **направено 1.11.2026 като разширение на камбаните**: `Bells.tension` (дял удари на полутон/тритон извън лада, разрешени в следващия удар; 10 % в световете) + „На такта“ (`Ambient.sync`, общ часовник с ритъма/песента; `Trigger::tick_on_grid`); отделен източник `events` не беше нужен — камбаните/семплерът вече са едноударни в лада | нов източник `events`: едноударни звуци (камбана/резонатор/пиано-подобен удар или семпъл от папка) с вероятност в минута, случайна сила, в лада; 10 % „напрежение“ (секунда/тритон) с разрешение в следващия удар | `LayerSource::events` + рендер в ambient | карта на модула в „Модули“; параметри Плътност, Сила±, Напрежение, Регистър | тест: 10 min симулация → брой събития ≈ плътност ± 20 %, всички в лада освен ≤ 12 % |
| **S3 Пулс** (1 ден) — **направен 4.11** (`pulse.rs`, `LayerSource::Pulse`, модул с Период / Присъствие / Цвят / Мекота, експорт, смоук) | неперкусионен пулс (филтриран тон/шум на такт или на секунди), появява се и изчезва на 2–3 min | `LayerSource::pulse` | модул с Период, Присъствие, Цвят | тест: огъвката има периоди на тишина |
| **S4 Дишане** (½ ден) | 1/f (Perlin-подобен) дрейф върху cutoff, space, плътност на събитията; дълбочина и период | `BreathLfo` в макросите (без allocation в callback) | копчета Дълбочина / Период | тест: стойностите са гладки (max dV/dt) и в граници |
| **S5 Орбита и разстояние** (1 ден) | всяко събитие орбитира (sin/cos, случаен период) и има разстояние = ниво + LP + reverb; Haas закъснение по избор (слушалки) | per-voice pan/LP/delay в events | Скорост на орбитата, Разстояние, Слушалки ☐ | тест: L/R корелация се мени, няма щракания |
| **S6 Реактивен диригент** (1 ден) | мониторът (вече работи) дава RMS/активност → `userActivity` 0..1 с бавно затихване; плътност = base + 0.4·activity; филтрите се отварят при силно свирене; при тишина > N s Bloom излиза отпред (соло линия) и се прибира при първата нота | — (четене на `MonitorStatus`) | превключвател „Слуша микрофона“, индикатор за активност | smoke (`--sound`): синтезиран вход → плътността расте |
| **S7 Светове** (½ ден) | 6 профила с бележки: *Древна гора*, *Дълбок космос*, *Киберпънк дъжд*, *Родопска нощ*, *Планинско утро*, *Тракийска степ*; всеки = стойка + арка + събития + пулс + дишане | — | карти с „Пробвай“ и „Запази като мой свят“ | smoke: всеки свят се зарежда и свири 2 s без грешки |
| **S8 Време и метео** (½ ден, **само с одобрение**) | час от системния часовник → ден/нощ профил (без мрежа); метео през Open-Meteo по избор (мрежова заявка, изрично включване) | — | „Следи часа“ ☐, „Следи времето навън“ ☐ (изкл. по подразбиране) | тест: без мрежа всичко работи |

Ред: S1 → S2 → S4 → S7 (вече звучи като композиция) → S3 → S5 → S6 → S8. Общо ≈ 7 дни.
