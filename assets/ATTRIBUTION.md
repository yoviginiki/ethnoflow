# Attribution

Sounds and audio assets distributed with EthnoFlow Studio. Rules: `docs/AUDIO-LICENSING.md`.
Machine-readable list: `asset-manifest.json` in this folder.

## Bundled audio files

None. All sounds in this release are synthesized at run time by the application's own
code (`crates/audio-engine`): noise colours, wind, resonator textures, FM/modal bells,
Karplus–Strong strings, the drone and the pad. No third-party recordings, sample packs
or sample-based instruments are included.

## Inspiration (no assets, code or UI copied)

- myNoise.net — the idea of a multi-slider soundscape that the listener mixes.
- Sonic Pi — algorithmic patterns as a way of thinking about generative layers.
- Freesound — as a source of licence vocabulary for the manifest; no files used.
